# AIS Cognitive Cycle

## Purpose

The AIS Cognitive Cycle defines the standard thinking process that every AIS component must follow before producing an output.

Regardless of the specialist agent involved (Marketing, Finance, HR, Customer Success, etc.), every reasoning process must follow this same cognitive framework.

This ensures consistency, explainability, reliability, and continuous learning throughout the AIS ecosystem.

# Stage 1 — Accept

Purpose:

Receive the user's request without making assumptions.

Inputs may include:

- User questions
- Business data
- Images
- Documents
- Audio
- External APIs
- Previous conversations

Output:

A complete input package ready for processing.

---

# Stage 2 — Access

Purpose:

Retrieve every piece of relevant knowledge before reasoning begins.

AIS may access:

- Business Intelligence Memory (BIM)
- Global Intelligence Memory (GIM)
- Pending Memory
- Knowledge Gap Memory
- Business Context
- Previous analyses
- Specialist agents
- External knowledge (if required)

Output:

Relevant information collected for reasoning.

---

# Stage 3 — Observe

Purpose:

Identify facts without interpreting them.

Examples:

• Sales are zero.

• TikTok is the primary marketing channel.

• No website was provided.

• Monthly revenue was not supplied.

Observation contains facts only.

No conclusions are made.

---

# Stage 4 — Organize

Purpose:

Classify information into meaningful categories.

Examples:

Identity

Operations

Marketing

Finance

Customers

Employees

Performance

Goals

Risks

Organized information becomes easier to analyze.

---

# Stage 5 — Analyze

Purpose:

Determine what the observations mean.

This stage identifies:

- Root causes
- Patterns
- Opportunities
- Risks
- Possible explanations

Specialist agents perform most of the analysis.

---

# Stage 6 — Crosscheck

Purpose:

Validate every conclusion before presenting it.

AIS verifies conclusions using:

- Evidence
- Confidence scores
- Global Intelligence Memory
- Business Intelligence Memory
- Other specialist agents
- Historical analyses

If confidence is below the required benchmark, AIS requests additional information instead of making assumptions.

---

# Stage 7 — Deliver Intelligence

Purpose:

Present the best recommendation available.

Every recommendation should include:

- Recommendation
- Supporting evidence
- Confidence score
- Risks
- Expected outcomes
- Alternative options (when appropriate)

AIS provides recommendations, not commands.

Final business decisions remain with the business owner.

---

# Stage 8 — Learn

Purpose:

Improve AIS after every completed interaction.

AIS evaluates:

- Was the recommendation successful?
- Was the confidence accurate?
- Should Business Intelligence Memory be updated?
- Should Global Intelligence Memory learn something?
- Was a new Knowledge Gap discovered?

Learning completes the cycle and prepares AIS for future interactions.

# Guiding Principle

Every AIS agent must think before acting.

The Cognitive Cycle standardizes that thinking process and ensures every recommendation is transparent, explainable, evidence-based, and continuously improving.
